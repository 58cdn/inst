# AI 工具

- 菜单 4 / `--agents` / `-Agents`：Claude Code、Codex、Gemini、OpenCode、Grok、OpenClaw、Hermes、Pi。按平台、项目支持情况选择官方脚本或 npm。
- 菜单 5 / `--desktop` / `-Desktop`：Claude、Codex/ChatGPT 桌面端。
- 菜单 6 / `--endpoint` / `-Endpoint`：合并 API 地址、模型配置；密钥仍从隐藏输入或 `INST_API_KEY` 读取，不新增明文密钥参数。

[应用与平台支持表](../../README.md#4-agents-cli)。现有官方安装流程不包含第三方激活脚本。
