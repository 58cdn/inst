# 开发环境

- 菜单 1 / `--node` / `-Node`：nvm 或 nvm-windows、Node.js LTS、npm、pnpm。
- 菜单 2 / `--python` / `-Python`：pyenv 或 pyenv-win、Python、Miniconda。
- 版本、平台和中国镜像选择沿用现有实现；Windows 独立 Node 与 nvm 冲突检测保留。
- `--dry-run` / `-DryRun` 仅预览；`--python-version` / `-PythonVersion` 指定 Python 版本。

详细参数与安装边界见 [README](../../README.md#功能)。
