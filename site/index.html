cross-platform setup / v1

开发环境，一条命令就绪。

inst 自动识别你的系统，安装 Node.js、Python、镜像源、AI Agents CLI 与桌面端。适用于 macOS、Linux、WSL、Git Bash 和 Windows。

从零开始，少走弯路交互菜单与参数模式并存，支持国内网络自动启用镜像。

快速开始

选择你的终端，复制命令并执行。

01 / Unix-like

macOS · Linux · WSL

也支持 bash、zsh 与 Git Bash。

curl -fsSL https://inst.linux.yun | sh
02 / PowerShell

Windows PowerShell

兼容 PowerShell 5.1 与 PowerShell 7。

irm https://inst.linux.yun | iex
03 / Command Prompt

Windows cmd

无需 PowerShell，使用系统自带命令提示符。

curl -fsSL https://inst.linux.yun/install.cmd -o %TEMP%\\inst.cmd && %TEMP%\\inst.cmd

需要完整脚本路径？ install.shinstall.ps1install.cmd

一次配置，持续可用

把常见开发工具与环境准备集中到一个入口。

01

Node.js 环境

nvm、Node.js LTS、npm 与 pnpm。

02

Python 环境

pyenv、Python 稳定版与 Miniconda。

03

镜像源配置

系统源、npm、pip、conda 与 Homebrew。

04

Agents CLI

Claude、Codex、Gemini、OpenCode 等工具。

05

桌面端

Claude Desktop 与 Codex，可指定安装目录。

06

地址配置

批量写入 API Base URL、模型与密钥。

带参数运行

支持非交互模式，例如 --all --dry-run。完整参数和安全约定见 GitHub README。

安装前先预览

使用 --dry-run 只查看将执行的步骤，不下载、不创建目录、不修改配置。
