inst

一条命令完成 Node.js、Python、镜像源、AI Agents CLI 与桌面端的安装。自动识别 Windows（PowerShell / cmd / Git Bash）、macOS 与 Linux（sh / bash / zsh），中国网络自动启用国内镜像。

macOS / Linux / WSL / Git Bash

curl -fsSL https://inst.linux.yun | sh

Windows PowerShell

irm https://inst.linux.yun | iex

Windows cmd

curl -fsSL https://inst.linux.yun/install.cmd -o %TEMP%\inst.cmd && %TEMP%\inst.cmd

根地址按 User-Agent 返回入口脚本，也可以使用完整路径：/install.sh、/install.ps1、/install.cmd。

功能

1 Node.jsnvm / nvm-windows、Node.js LTS、npm、pnpm
2 Pythonpyenv / pyenv-win、Python 最新稳定版、Miniconda
3 镜像系统源（apt / dnf / apk / pacman / Homebrew）、npm、pip、conda；清华、阿里云、中科大、腾讯云、华为云
4 Agents CLIClaude Code、Codex、Gemini CLI、OpenCode、Grok Build、OpenClaw、Hermes、Pi（官方脚本或 npm）
5 桌面端Claude Desktop、Codex（ChatGPT 桌面端），可指定安装目录
6 地址配置一键写入各 Agent 的 API Base URL、模型与密钥
00 更新版本检查、校验后替换并备份，支持每日自动更新

带参数运行：curl -fsSL https://inst.linux.yun | sh -s -- --all --dry-run。完整说明见 GitHub。
